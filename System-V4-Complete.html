📚 شرح الجداول الاحترافية V4 - هرمية متكاملة
1- القطاعات: قطاع دمياط، المنصورة، القاهرة
2- المحطات: قطاع → محطة (توليد/نقل/توزيع) - منع تكرار الاسم في نفس القطاع
3- الإدارات العامة: قطاع → إدارة عامة (موارد بشرية، مالية، فنية)
4- الإدارات: إدارة عامة → إدارة فرعية (شئون عاملين، تدريب)
5- المجموعات الوظيفية: هندسية، فنية، إدارية، مالية
6- الوظائف: مجموعة → وظيفة + مستوى وظيفي (قيادي، إشرافي، تخصصي، فني)
7- تخصصات الوظائف: وظيفة → تخصص دقيق (مهندس كهرباء قوى، فني كهرباء صيانة)
8- فئات المؤهلات: دكتوراه، ماجستير، بكالوريوس، ليسانس، دبلوم...
9- أنواع المؤهلات: فئة → نوع (بكالوريوس → هندسة، تجارة)
10- تخصصات المؤهلات: نوع → تخصص (هندسة → كهرباء قوى)
11- الكادر → درجة → فئة مالية بمرتب
12- الموظفون: يربط بكل المستوى الثالث (تخصص وظيفة + تخصص مؤهل + فئة مالية)
13- Change_Salarey: متغيرات شهرية (تعديل أساسي، بدل ورادي، بدل غذاء...)
